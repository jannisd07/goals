Goals is an Expo 55 / React Native 0.83 iOS app. Agents drive it through
`.claude/skills/run-goals/sim.sh` (a `simctl` wrapper for rebuild, launch,
screenshots, logs, state, location and tests) plus computer-use clicks on the
Simulator window for taps. All paths are relative to the repo root.

## Prerequisites

Verified 2026-09-10 on Jannis' Mac: Xcode 26.6, Node 25.2.1, iPhone 16 Pro
simulator on iOS 18.6 with the app (`com.vibetime.app`) installed, `.env` with
`EXPO_PUBLIC_SUPABASE_URL` and `EXPO_PUBLIC_SUPABASE_ANON_KEY`.

```bash
.claude/skills/run-goals/sim.sh doctor
```

Expect `booted:` with a UDID, `app:` with a path, and both env keys listed.

## Run (agent path)

```bash
.claude/skills/run-goals/sim.sh boot
.claude/skills/run-goals/sim.sh bundle
.claude/skills/run-goals/sim.sh shot home
```

`bundle` rebuilds only the JS bundle straight into the installed Release app and
restarts it (about 7 s). This is the path for every JS/TS change. `shot` writes
`/tmp/goals-shots/home.png` and a 900px `home.small.png`; read the small one.

| command | what it does |
|---|---|
| `doctor` | toolchain, booted device, installed app, `.env` keys, free disk |
| `boot [name]` | boot a device if none is booted (default iPhone 16 Pro), open Simulator.app |
| `bundle` | rebuild JS into the installed app + restart |
| `restart` / `launch` / `stop` | app lifecycle |
| `shot [name]` | screenshot to `/tmp/goals-shots/` |
| `logs [all] [secs] [lines]` | JS console output (default last 600 s); `all` adds native noise |
| `state` | persisted AsyncStorage summary: signed in, onboarding done, pending setup |
| `location <lat>,<lon>` / `location clear` | simulated GPS for geofences |
| `grant [service]` | privacy grant without prompt, default `location-always` (kills the app) |
| `appearance light\|dark` | system appearance |
| `statusbar` | 9:41 status bar for clean screenshots |
| `test` | typecheck + domain smoke tests |
| `build-native` / `install` | full Release simulator build — blocked on this Mac, see below |

### Tapping, typing, scrolling

There is no scripted tap. Use computer-use on the Simulator window:
`request_access` for Simulator → `open_application` → wait 1–2 s → `screenshot`
→ `left_click` at coordinates from that screenshot (full-resolution frame, not the
scaled image). Scroll with `left_click_drag` upward, never on a map. Take a fresh
screenshot after every navigation, because header buttons swap meaning between
steps (Close on step 1 is Save on step 2 in the Auto Check-In editor).

### Debugging a bug report

```bash
.claude/skills/run-goals/sim.sh logs 1800 20
.claude/skills/run-goals/sim.sh state
```

`logs` surfaces caught JS errors such as Supabase permission errors that the UI
swallows. `state` answers "why is it signed out / why did my setup vanish"
without printing tokens.

### Auto Check-In

```bash
.claude/skills/run-goals/sim.sh grant location-always
.claude/skills/run-goals/sim.sh restart
.claude/skills/run-goals/sim.sh location 48.3984,9.9916
.claude/skills/run-goals/sim.sh location clear
```

`grant` terminates the app, hence the `restart`.

### Screenshots for design review

```bash
.claude/skills/run-goals/sim.sh statusbar
.claude/skills/run-goals/sim.sh appearance light
```

## Build (native)

Only needed after native changes (new native package, `app.json` plugins,
Podfile). `sim.sh build-native` runs `xcodebuild` for Release on
`generic/platform=iOS Simulator` into `ios/build` and installs the result.

**Currently blocked:** Xcode 26.6 ships the iOS 26.5 simulator SDK but only the
iOS 18.6 runtime is installed, so `xcodebuild` finds no simulator destination at
all. It needs the iOS 26.5 simulator platform from Xcode › Settings › Components,
which is a multi-GB download with about 11 GiB free. Ask Jannis before
downloading. The installed app came from an earlier Xcode beta build; JS changes
still reach it through `bundle`.

`ios/` is generated by Expo prebuild and gitignored.

## Test

```bash
.claude/skills/run-goals/sim.sh test
```

Typecheck passes silently, then `Domain smoke tests passed: 115 assertions.`
About 5 s. Small design changes skip this (fast path in `CLAUDE.md`: edit,
review, `bundle`).

## Gotchas

- **Launch frames:** after `bundle`/`restart` the screen is black at first, then
  shows the loading spinner on the ocean. `shot` waits until the middle band is not
  black and three coarse samples in a row match (about 5 s after a restart). File size does not
  work as a signal: a flat paper screen is smaller than the black frame.
- **Stale bundle:** the Release app runs the embedded `main.jsbundle`. Xcode does
  not reliably regenerate it, which looks like "nothing changed". Always push JS
  with `sim.sh bundle`.
- **Debug builds are useless here:** `expo-dev-client` is installed, so a Debug
  build opens the dev launcher and waits for Metro. Stay on Release.
- **Environment:** a stale `DEVELOPER_DIR` points at a removed Xcode beta, and
  CocoaPods and Xcode script phases fail without a UTF-8 locale. The driver unsets
  and exports both.
- **The iOS Simulator MCP tool can't see this device.** It answers "No booted
  simulator found" for the iOS 18.6 device, so use computer-use.
- **No host-side tap injection:** `osascript` has no Accessibility
  (`UI elements enabled` → false) and idb is not installed. Installing idb
  would need Jannis' OK.
- **Simulator on another Space:** `open_application` says so. Wait 1–2 s and take
  a screenshot, and the window comes forward.
- **Mouse-wheel scrolling does nothing** in React Native ScrollViews inside
  Simulator. Drag instead. A drag that starts on a MapView pans the map.
- **Signed out:** the simulator loses its Supabase session after some restarts
  (`state` shows `signed in (userConfig): False`). Agents have no credentials;
  ask Jannis to sign in. Onboarding and setup pages work signed out.
- **Expected log noise:** `[expo-notifications] Error reading persisted server
  registration info ... Keychain access failed ... -34018` on every launch.
  The simulator lacks the entitlement; ignore it.
- **zsh:** the driver is bash on purpose. In the default zsh, `$PIPESTATUS` is
  empty and a glob over a missing directory aborts the whole command (`nomatch`).

## Troubleshooting

- **`xcodebuild: error: Unable to find a destination matching the provided destination specifier ... iOS 26.5 is not installed`**:
  missing simulator platform, see "Build (native)".
- **`Failed to flush onboarding setup: ... permission denied for table users` (42501) in `logs`**:
  a PostgREST `upsert` on `users` hits the column-level UPDATE grants.
  `ON CONFLICT DO NOTHING` fails too, on the `users_display_name_valid` CHECK
  (23514). Don't upsert `users`; update it or check that the row exists.
- **`No booted simulator found` from the MCP simulator tool**: expected here, use computer-use.
- **`error: app not installed on booted; run build-native first`**: the app is
  gone from the device. Native builds are blocked, so ask Jannis.
